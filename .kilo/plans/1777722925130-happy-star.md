# Execution Plan: FinSight AI Critical Gaps & Production Hardening
*Status: Ready for Implementation | Priority: CRITICAL*

## Executive Summary
Based on extreme codebase audit, the system has strong architectural foundations but is **NOT production-ready** due to:
1. **CitationGuard completely missing** (security/compliance blocker)
2. **Demo mode hardcoded** (no real data capability)
3. **Watchlist shows stale/hardcoded data** (not connected to live feeds)
4. **Chart disconnected from real historical data** (uses dummy generator)
5. **Alert system non-functional** (no threshold evaluation)
6. **Missing audit trail from agent nodes**

## Root Cause Analysis
- `DEMO_MODE=1` forces all API clients to return fixtures instead of real data
- CitationGuard exists in MVP plan but **0% implemented** (frontend + backend)
- Dashboard feeds StatCards from hardcoded `INITIAL_TICKERS` array, not DB
- CandleChart uses PRNG seed instead of `/quotes/{symbol}/history` endpoint
- Alert evaluator service missing; agent never triggers alerts from live ticks
- Audit writes only on query submission, not per-agent execution

## Phase 5: Alert System Activation - 1 hour
**Goal**: Evaluate position thresholds on live quote ticks and emit alerts

### Files to Modify:

#### 1. `backend/app/services/alert_evaluator.py` (NEW)
```python
import asyncio
from typing import Dict, List
from app.services.ws_hub import ws_hub
from sqlalchemy.ext.asyncio import AsyncSession
from app import models

class AlertEvaluator:
    def __init__(self, db: AsyncSession):
        self.db = db
        self.active_alerts: Dict[str, bool] = {}  # symbol -> triggered state
    
    async def evaluate_position_thresholds(self, symbol: str, price: float):
        # Get all positions for this symbol across all users
        result = await self.db.execute(
            models.Position.query.where(
                models.Position.symbol == symbol,
                models.Position.alert_threshold.isnot(None)
            )
        )
        positions = result.scalars().all()
        
        for position in positions:
            if position.alert_threshold and price >= position.alert_threshold:
                alert_key = f"{position.user_id}-{position.symbol}-{position.id}"
                
                # Prevent duplicate alerts
                if alert_key not in self.active_alerts:
                    self.active_alerts[alert_key] = True
                    
                    await ws_hub.publish_to_user(
                        position.user_id,
                        {
                            "type": "alert",
                            "symbol": symbol,
                            "price": price,
                            "position_id": position.id,
                            "message": f"{symbol} reached ${price:.2f} (threshold: ${position.alert_threshold})"
                        }
                    )
    
    async def reset_symbol_alerts(self, symbol: str):
        """Reset alerts when price falls below threshold"""
        keys_to_remove = [
            k for k in self.active_alerts.keys() 
            if f"-{symbol}-" in k
        ]
        for k in keys_to_remove:
            del self.active_alerts[k]
```

## Risk Assessment

### High Risk:
- **API Quota Exhaustion**: Gemini/Finnhub free tier may run out during testing
  - *Mitigation*: Cache aggressively, implement rate limits, fallback to demo
- **WebSocket Overload**: 100+ users × 4 ticks/sec = 400 msg/sec
  - *Mitigation*: Throttle broadcasts to 1/15s per symbol, per-user queues

### Medium Risk:
- **Data Inconsistency**: Real-time prices may differ from historical aggregates
  - *Mitigation*: Use single source of truth (yfinance) for both
- **Stale Cache**: News sentiment doesn't update for hours
  - *Mitigation*: Schedule NewsNode to run every 30min, not just on query

### Low Risk:
- **UI Glitches**: Flash animations on rapid P&L changes
  - *Mitigation*: Debounce state updates (100ms)
